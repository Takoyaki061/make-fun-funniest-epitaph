Entry for make.fun's ["Famous Last Words: The Funniest Epitaph"](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty ($2 in USDC).

The epitaph — the dead man's famous last words, carved in stone:

> I've hidden a fortune somewhere in this graveyard. Good luck, suckers.

`main.py` (Python 3.13, stdlib only) writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt` when set).
